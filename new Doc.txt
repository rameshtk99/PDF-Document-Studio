# 8. HIGH-PERFORMANCE PDF VIEWER

Implement a proper viewport-based rendering architecture.

Do NOT repeatedly render entire large pages whenever the user moves the viewport.

Use:

```text
PDF page
   ↓
render tiles
   ↓
tile cache
   ↓
viewport
   ↓
GPU/display
```

The renderer should:

* render visible regions first
* prefetch nearby regions
* cache rendered tiles
* evict distant tiles
* avoid unnecessary re-rendering
* reuse cached content
* invalidate only affected regions
* handle zoom intelligently
* handle rotation efficiently

Scrolling must feel continuous.

Zooming must feel responsive.

Do not sacrifice responsiveness merely because the PDF is large.
